# QuizMaster — Python Flask Quiz Game

A fun and interactive quiz game built with Python Flask!

## Live Demo :- https://Pooja2007.pythonanywhere.com

## Features
- ✅ 8 Topics — Science, History, Geography, Technology, Sports, Movies, Music, Literature
- ✅ 3 Difficulty Levels — Easy, Medium, Hard
- ✅ Countdown Timer per Question
- ✅ Score Tracking
- ✅ Answer Review at the End
- ✅ Fully Offline — No API Key Needed

## Built With
- Python 3
- Flask
- HTML, CSS, JavaScript
- JSON (for questions database)

## 🚀 Run Locally

**Step 1:** Clone the repository
```bash
git clone https://github.com/srilehkakada-dot/quiz-game.git
```

**Step 2:** Go into the folder
```bash
cd quiz-game
```

**Step 3:** Create virtual environment
```bash
python -m venv venv
venv\Scripts\activate
```

**Step 4:** Install dependencies
```bash
pip install flask
```

**Step 5:** Run the app
```bash
python app.py
```

**Step 6:** Open browser
